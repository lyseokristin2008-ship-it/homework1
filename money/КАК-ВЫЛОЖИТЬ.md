# Как выложить сайт в интернет 🌸

Сайт полностью статический — работает без сервера и баз данных.
Достаточно отдать папку `money` любому бесплатному хостингу.

## Что в папке
| Файл | Что это |
|---|---|
| `index.html` | сама страница |
| `style.css` | розовая няшная тема |
| `script.js` | кнопки, копирование номера, сердечки |
| `qr.jpg` | твой QR-код для перевода |
| `photo_2026-11-25_00-24-40.jpg` | исходник QR (можно удалить) |

**Что уже вшито:** номер `+7 952 836-38-44` (показывается целиком, копируется в формате `+79528363844`).

## Вариант 1. Netlify Drop (самый быстрый, ~1 минута)
1. Открой https://app.netlify.com/drop
2. Перетащи в окно **папку** `деньги`.
3. Через пару секунд получишь ссылку вида `https://smth-random.netlify.app`.
4. Регистрация не обязательна, но если войдёшь — ссылку можно переименовать
   (`Site settings → Change site name`) и она не пропадёт.

## Вариант 2. GitHub Pages (уже подготовлено)
В репозитории есть готовый workflow `.github/workflows/pages.yml`, который публикует папку `money`.
Что сделать один раз:
1. Загрузить репозиторий на GitHub (ветка `main`).
2. На GitHub: `Settings → Pages → Build and deployment → Source` → выбрать **GitHub Actions**.
3. После первого пуша в `main` workflow прогонится сам (или запусти вручную: вкладка `Actions` → «Deploy site to GitHub Pages» → `Run workflow`).

Ссылка сайта получится:
`https://lyseokristin2008-ship-it.github.io/homework1/`

> 💡 Почему через Actions, а не «Deploy from a branch»:
> при публикации из ветки GitHub разрешает только **корень репозитория** или папку **`docs`**.
> Раз сайт лежит в `money`, его публикует workflow — это штатный способ GitHub.

## Вариант 3. Cloudflare Pages / Vercel
Аналогично: подключить репозиторий или перетащить папку, выбрать статический сайт без сборки.

## Как поменять номер или QR
- **Номер**: в `index.html` найди `+7 952 836-38-44` и замени.
  В `script.js` поправь `PHONE_PRETTY` и `PHONE_RAW` (второй — для копирования без пробелов).
- **QR**: сгенерируй новый QR в банковском приложении (раздел «QR-код / СБП»),
  сохрани скриншот и положи в папку как `qr.jpg` (перезаписав старый).

## Мелочи
- Счётчик «Милоты собрано» — игровой, хранится только в браузере каждого гостя
  (`localStorage`). Реальные переводы он не видит, зато весело 😊
- Ничего не ломается без интернета: внешних библиотек и CDN нет.
